Run for Shubh Bohra (final-year CS-Design, Dayananda Sagar College of Engineering). Sourced live via the Apify LinkedIn Jobs Scraper (`bebity/linkedin-jobs-scraper`) across 6 scraper runs:

- Bengaluru, on-site/hybrid × 9 target titles (AI Engineer / ML / Python Dev / Backend / GenAI / Software Engineer / Data Science / LLM Engineer / NLP Intern), internships posted in the last 7 days
- India, remote × 8 target + niche titles (LLM/RAG/Conversational AI/AI Agent Intern), internships posted in the last 7 days
- Direct company checks for AI-native Indian startups (Sarvam AI, Krutrim, Yellow.ai, Haptik, Uniphore, Observe.AI, Groq, Fractal) — **0 open internship postings found**

These were excluded per the filtering rules (spammy/duplicate, mass-recruiter pattern). After filtering, **9 postings genuinely qualified** — returned as-is rather than padded to 20.
